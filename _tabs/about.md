# def0ult

I'm into cybersecurity, mostly the offensive side. I like figuring out how vulnerabilities actually work and why things break, and I'm usually happiest when I have a lab running and something to tear apart.

My day job is DevOps and sysadmin stuff, so I spend a lot of time around servers, infrastructure and deployments. It helps a lot with the security side too. It's easier to break something when you know how it's supposed to be set up.

I also build CTF machines and labs now and then. I try to make them feel like real systems instead of "guess the magic parameter" puzzles.

I started this blog to keep my notes somewhere I can find them later. It's got my research, experiments, write-ups and random projects. I'm still learning, so expect some mistakes along the way. If something here helps you, great.
